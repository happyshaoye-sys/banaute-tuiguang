# MetoX v2.27 半自动推广工具

应用版本：MetoX v2.27

外部策略算法版本：v9.3（独立版本，本次未变更）

## v2.27 核心变更

- “生成全部 Sheet Excel”改为点击后即时生成并直接下载，不再把整份工作簿字节保存在 Streamlit 会话状态中。
- 下载完成后不触发整页重跑，降低大数据量导出时后台进程异常退出的风险。
- 本次仅调整下载触发和文件传输方式；工作表、字段、公式、聚合方式、指标结果和业务判断全部保持不变。
- 已用 15,151 行真实执行表连续下载两次，服务均保持在线且无新增 Windows 崩溃事件。

## 延续的 v2.26 核心变更

## 延续的 v2.25 核心变更

- 新增跨分析日复用的逐日事实缓存：28 日窗口中未变化的历史日期不再重复解析和聚合。
- 商品资料、聚水潭库存快照和退款率快照使用独立共享维度缓存；每次仍把当前维度挂回日事实，不冻结旧库存、退款率、成本或货号。
- 缓存按源路径、数据类型、文件大小和纳秒级修改时间自动失效；读取期间源文件发生变化时拒绝写入，损坏缓存自动回退重算。
- 缓存文件采用同目录临时文件加原子替换，加载日志新增“日事实缓存命中/未命中”统计。
- 真实 28 日验证：强制冷读 395.164 秒，热缓存 52.359 秒，提速 7.547 倍；28/28 天命中，16,961 行和 254 个计划 ID 与冷读结果完全一致。
- 周期环比、滚动日销、核心指标状态和 MetoX 算法继续实时计算；v2.25 的缓存优化未修改业务口径。

## 版本治理

- `VERSION.json` 是唯一版本源。
- `core/version.py` 从唯一版本源派生页面显示版本。
- `scripts/release_check.py` 检查业务规则变更是否升版，并校验页面、文档、分支和阈值契约。
- `scripts/release_metox.py` 先执行发布检查，再生成带版本和日期的不可覆盖目录与 ZIP。
- Git 发布标签使用 `MetoX<版本>`，例如 `MetoX2.2`。

## 核心文件

- `core/metox_algorithm.py`：MetoX 内置算法。
- `core/v93_signal.py`：v9.3 日报信号解析。
- `core/segmentation.py`：36 宫格、风险标签、动作和优先级。
- `core/analysis.py` / `core/exporter.py`：页面和 Excel 分析口径。
- `core/merge.py` / `core/periods.py`：数据合并和周期聚合。
