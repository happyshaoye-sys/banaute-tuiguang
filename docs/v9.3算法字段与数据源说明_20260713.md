# v9.3算法字段与数据源说明

适用范围：半自动推广工具内置 v9.3 算法。  
代码位置：`半自动推广工具_离线版_20260706_173620/core/v93_algorithm.py`。  
结论先行：`v9.3算法命中 / v9.3算法分 / v9.3算法原因` 不是读取外部 v9.3 结果文件，而是工具加载当天及历史日期数据后，由内置算法实时计算出来。

## 1. 算法输出字段

| 执行表字段 | 含义 | 生成位置 | 说明 |
|---|---|---|---|
| v9.3算法命中 | 命中的动作标签 | `v93_algorithm.py` | 可能包含 `明日之星`、`爆发`、`潜力款`、`加预算`、`保护持有`、`饱和观察`、`削减`、`溢出` 等，多标签用 `|` 拼接。 |
| v9.3算法分 | 命中标签的累计分 | `v93_algorithm.py` | 各业务门槛命中后加减分，用于排序和解释强弱。 |
| v9.3算法原因 | 命中原因明细 | `v93_algorithm.py` | 输出 ROI、自然 GMV 占比、加购成本、7日花费、自然访客、加购率等解释文本。 |

| 算法字段 | 执行表字段 | 优先级 / 计算方式 | 主要来源表 | 原始字段 |
|---|---|---|---|---|
| 商品ID | 宝贝ID | 商品维度主键 | 商品-经营投产比 / 无界-商品主体 / 商品资料 | 宝贝ID、商品ID、主体ID 等别名 |
| 类目 | 淘宝类目 | 商品维度字段 | 商品-经营投产比 | 淘宝类目、类目、品类、叶子类目等别名 |
| 商品名称 | 商品名称 | 商品维度字段 | 商品-经营投产比 | 商品名称、商品标题、标题等别名 |
| GMV | GMV | 优先商品-经营投产比；无商品表时可由无界表进入合并结果 | 商品-经营投产比为主；无界-商品主体为备 | GMV、销售额、成交金额、支付金额、总成交金额 |
| 商品访客 | 商品访客数 | 商品总访客 | 商品-经营投产比 | 商品访客数、访客数、流量、UV、引导访问量 |
| 商品加购 | 商品加购件数 | 商品总加购 | 商品-经营投产比 | 商品加购件数、加购件数、总购物车数、总收藏加购数 |
| v9.3推广花费 | v9.3推广花费 | 算法使用；按日、按商品汇总 `转化周期=15天` 的付费 | 无界-商品主体 | 付费、广告费、消耗、花费 |
| v9.3推广成交 | v9.3推广成交金额 | 算法优先使用；用于自然 GMV / 溢出判断 | 商品-经营投产比 | 推广引导总成交金额 |
| v9.3推广访客 | v9.3推广访客数 | 关键词、人群、场景推广访客相加 | 商品-经营投产比 | 关键词推广访客数 + 人群推广访客数 + 场景推广访客数 |
| v9.3推广加购 | v9.3推广加购数 | 优先推广加购人数相加；否则用推广总加购数；再否则用推广加购数相加 | 商品-经营投产比 | 关键词推广加购人数 + 人群推广加购人数 + 场景推广加购人数；或推广总加购数；或关键词/人群/场景推广加购数 |
| 执行表付费 | 付费 | 同样来自 `转化周期=15天` 的无界付费；当前与 `v9.3推广花费` 同源 | 无界-商品主体 | 付费、广告费、消耗、花费 |
| 普通推广成交 | 推广成交金额 | 无界行级 `GMV` 有值用 GMV，否则用 `付费 × 推广投产` 重构 | 无界-商品主体 | 总成交金额 / GMV，投入产出比 / 推广投产，付费 |
| 普通推广加购 | 推广加购数 | 无界计划明细加总 | 无界-商品主体 | 推广加购数、推广加购件数、广告加购数、总购物车数 |
| 推广明细 | 推广明细 | 按计划聚合 Top 3，供计划数、最高计划 ROI、计划加购回填 | 无界-商品主体 | 计划ID、付费、推广投产、商品加购件数 |

| 支付件数 | 支付件数 | 价格兜底计算使用 | 商品-经营投产比 | 支付件数、成交件数、销量 |

## 3. 时间窗口口径

| 算法内部指标 | 计算窗口 | 计算口径 |
|---|---:|---|
| 昨日指标 | 1天 | 当前选择日期当天，例如 2026-07-09。 |
| 近3日指标 | 3天 | 当前日期向前含当天 3 天。 |
| 近7日指标 | 7天 | 当前日期向前含当天 7 天。 |
| 上一个3日基线 | 3天 | 近3日前一段 3 天，用于增长判断。 |
| 店铺 ROI 基准 | 7天 | 店铺层面 GMV ÷ v9.3推广花费。 |

示例：当前日期为 `2026-07-09`，7日窗口为 `2026-07-03` 到 `2026-07-09`。

## 4. 内置算法使用字段明细

### 4.1 明日之星 / focus

| 判断项 | 使用字段 | 来源说明 |
|---|---|---|
| 是否已有推广计划 | `v9.3推广花费` 或 `付费` 或 `推广明细` | 花费来自无界15天付费；也会看计划明细。 |
| 7日自然访客 | `商品访客数 - v9.3推广访客数` | 商品访客来自商品-经营投产比；推广访客来自商品-经营投产比的关键词/人群/场景推广访客。 |
| 7日总加购 | `商品加购件数` | 商品-经营投产比。 |
| 昨日自然访客 | 昨日 `商品访客数 - v9.3推广访客数` | 同上。 |
| 昨日加购 | 昨日 `商品加购件数` | 商品-经营投产比。 |
| 昨日自然加购率 | 昨日自然加购 ÷ 昨日自然访客 | 由总加购扣除推广加购后计算。 |
| 近3日加购 / GMV 增长 | `商品加购件数`、`GMV` | 与上一段 3 日窗口对比。 |
| 7日花费 | `v9.3推广花费` | 无界-商品主体15天转化行 `付费`。 |
| 计划数 / 最高计划 ROI | `推广明细` | 无界-商品主体计划明细聚合。 |

### 4.2 recent

| 判断项 | 使用字段 | 来源说明 |
|---|---|---|
| 近3日加购 | 商品加购件数 | 商品-经营投产比。 |
| 近3日花费 | v9.3推广花费 | 无界-商品主体15天转化行 `付费`。 |
| 近3日加购率 | 商品加购件数 ÷ 商品访客数 | 商品-经营投产比。 |

### 4.3 scale_up / 爆发

| 判断项 | 使用字段 | 来源说明 |
|---|---|---|
| 昨日加购 | 商品加购件数 | 商品-经营投产比。 |
| 基线加购 | 前3日商品加购日均 | 商品-经营投产比。 |
| 昨日自然加购 | 商品加购件数 - v9.3推广加购数 | 商品-经营投产比。 |
| 基线自然加购 | 前3日商品加购日均 - 前3日推广加购日均 | 商品-经营投产比。 |
| 昨日花费 | v9.3推广花费 | 无界-商品主体15天转化行 `付费`。 |

### 4.4 loss_hole / 亏损洞

| 判断项 | 使用字段 | 来源说明 |
|---|---|---|
| 昨日花费 | v9.3推广花费 | 无界-商品主体15天转化行 `付费`。 |
| 昨日 ROI | 昨日 GMV ÷ 昨日花费 | GMV 来自商品-经营投产比；花费来自无界15天付费。 |
| 昨日加购率 | 昨日商品加购件数 ÷ 昨日商品访客数 | 商品-经营投产比。 |
| 3日 ROI | 近3日 GMV ÷ 近3日花费 | 同上。 |
| 7日 ROI | 近7日 GMV ÷ 近7日花费 | 同上。 |
| 溢出 ROI | `(7日GMV - 7日v9.3推广成交金额) ÷ 7日花费` | 自然 GMV 用总 GMV 扣推广成交。 |

### 4.5 rebalance_add / 加预算、保护、削减

| 判断项 | 使用字段 | 来源说明 |
|---|---|---|
| 7日花费 | v9.3推广花费 | 无界-商品主体15天转化行 `付费`。 |
| 7日 ROI | 7日 GMV ÷ 7日花费 | GMV 来自商品-经营投产比。 |
| 自然 GMV 占比 | `(7日GMV - 7日v9.3推广成交金额) ÷ 7日GMV` | 推广成交来自商品-经营投产比。 |
| 商品加购率 | 7日商品加购件数 ÷ 7日商品访客数 | 商品-经营投产比。 |
| 加购成本 | 7日花费 ÷ 7日v9.3推广加购数 | 推广加购优先商品-经营投产比。 |
| 3日增投 | 近3日花费 - 前3日花费 | 花费来自无界15天付费。 |
| mROI | `(近3日GMV - 前3日GMV) ÷ (近3日花费 - 前3日花费)` | 用于饱和观察。 |
| 价格档位 | 件单价；缺失时 GMV ÷ 支付件数 | 用于加购率阈值和加购成本阈值。 |
| 类目 / 价格段动态阈值 | 淘宝类目、件单价、7日自然访客/自然加购、推广花费/推广加购 | 先按价格段和类目形成动态线，样本不足时用默认阈值。 |

### 4.6 spillover / 溢出

| 判断项 | 使用字段 | 来源说明 |
|---|---|---|
| 7日花费 | v9.3推广花费 | 无界-商品主体15天转化行 `付费`。 |
| 自然 GMV | 7日GMV - 7日v9.3推广成交金额 | 商品-经营投产比。 |
| 溢出值 | 自然 GMV ÷ 7日花费 | 原因中显示为 `溢出:x.x,自然GMVxxxx,7日花费xxxx`。 |

## 6. 当前需要特别注意的口径

1. `v9.3算法原因` 里的 `7日花费` 取 `v9.3推广花费`，而 `v9.3推广花费` 来自无界-商品主体 `转化周期=15天` 的 `付费`。
2. 商品-经营投产比里的 `推广消耗金额` 不再作为 `v9.3推广花费` 来源，避免某天商品表花费为空时低估真实投放消耗。
3. `加购成本` 的公式是 `7日花费 ÷ 7日v9.3推广加购数`，其中 7日花费来自无界15天付费，推广加购仍优先来自商品-经营投产比。
4. `自然 GMV` 是算法推算值，公式为 `总GMV - v9.3推广成交金额`，不是源表直接给出的自然 GMV。
