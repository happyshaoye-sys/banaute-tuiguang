MetoX v2.3 半自动推广工具 - 离线版使用说明

外部策略算法版本：v9.3
更新日期：2026-08-02

v2.3 页面调整

1. 侧边栏默认只保留“日期”“时间周期”和“加载并处理数据”。
2. 数据根目录、路径配置、数据源目录、自定义分界点、性能耗时、周期完整性和 Git 版本管理统一收进“高级设置”。
3. “重新应用分界点”位于“高级设置”中的“自定义分界点”区域；只重算分层，不重新读取数据。
4. 数据看板六项指标下新增“AI经营日报”，按所选周期展示总览、等级、品类、三渠道和ROI风险五行摘要。
5. 日报在本机按固定公式生成，不联网调用AI；三渠道金额指广告归因成交变化，不是全店GMV贡献。
6. 当前期或对比期缺少日期时，日报只显示“暂估总览”，不输出驱动和风险强结论。

1. 先完整解压压缩包，不要只双击压缩包里的文件。
2. 双击“启动MetoX半自动推广工具.bat”。
3. 浏览器会自动打开；如未自动打开，请复制启动窗口中 METOX_URL= 后面的实际地址。
4. 使用期间不要关闭黑色启动窗口，关闭窗口即停止工具。
5. 启动脚本固定运行随包的 TuiGuangTool.exe；该启动器会执行同目录的 app.py 与 core 源码。
6. 不要删除 TuiGuangTool.exe、_internal、app.py、core、.streamlit、聚水潭 等文件夹或文件。

启动入口说明

普通用户只双击“启动MetoX半自动推广工具.bat”。
TuiGuangTool.exe 是 BAT 内部调用的实际程序；“启动半自动推广工具.bat”仅为旧文件名兼容入口，三者不是三套不同工具。

默认优先端口：8765
如端口已被占用，启动器会自动选择后续可用端口，并在窗口显示实际地址；无需手工改端口。

v2.0 起沿用的退款风险规则

1. 退款率 >80%：只标记「极高退款」，放量类动作降为「待优化」。
2. 退款率 >70% 且 ≤80%：标记「高退款」，放量类动作降为「待优化」。
3. 页面和 Excel 退款风险表均按严格 >70% 入选。
4. P1/P4 预算优先级的 40% 低退款门槛本次未改。

数据目录说明

主数据根目录默认使用：
  \\10.1.22.253\天猫mark

聚水潭库存快照优先使用：
  \\10.1.22.253\天猫mark\mark0706啊\聚水潭

聚水潭退款率快照根目录优先使用：
  \\10.1.22.253\天猫mark\mark0706啊\聚水潭\退款率快照

注意：侧边栏“聚水潭退款率目录”只填写上述根目录，不要追加 2026-07、2026-08 等月份目录。工具会按分析日期自动进入 YYYY-MM 子目录查找 `退款率_YYYY-MM-DD.csv`。

退款率快照每天上午 08:30 自动生成，文件日期为前一完整自然日；口径为近30天下单 cohort 的 `SUM(refund_amount)/SUM(amount)`，覆盖女装旗舰店和集团旗舰店。

聚水潭商品资料映射表使用工具内随附的“聚水潭\店铺商品资料_聚水潭映射.csv”作为兜底；公司共享盘如有同名映射表，也可在侧边栏手动改到共享盘目录。

库存快照日更规则：
  根目录：\\10.1.22.253\天猫mark\mark0706啊\聚水潭\库存快照
  月目录：YYYY-MM，例如 2026-07、2026-08
  文件名：库存快照_YYYY-MM-DD_款式级.csv

例如：
  \\10.1.22.253\天猫mark\mark0706啊\聚水潭\库存快照\2026-07\库存快照_2026-07-15_款式级.csv

8 月开始时，日更脚本会自动在“库存快照”目录下创建 2026-08 文件夹，以后月份同理。

执行表字段来源

以下字段按宝贝ID映射到对应日期的款式级库存快照：
  宝贝ID、货号、款式主图、创建时间、在仓库存、在途、成本价（含税）

快照中缺某个宝贝ID时，执行表对应字段会为空；补齐共享盘快照后，重新点击“加载并处理数据”即可刷新。

  在仓库存：0

离线兜底

压缩包内随附“聚水潭”兜底数据。公司网络能访问共享盘时，库存和退款率均优先读取共享盘最新日更快照；共享盘不可用时，才使用随包快照数据。

如果仍看到上述字段为空：
1. 确认启动的是本次新版压缩包里的 bat。
2. 确认侧边栏“聚水潭库存快照目录”指向共享盘 mark0706啊 下的“聚水潭\库存快照”目录。
3. 重新点击“加载并处理数据”。

如果“退款率”整列显示 None：
1. 确认侧边栏“聚水潭退款率目录”填写的是 `\\10.1.22.253\天猫mark\mark0706啊\聚水潭\退款率快照`。
2. 不要在目录末尾追加月份；否则程序会重复拼接月份而找不到文件。
3. 确认对应分析日或其前7天存在退款率快照，然后重新点击“加载并处理数据”。
